---
name: hh-elevate
description: Plan one Elevate round. Applying a pick needs the user's yes.
user-invocable: true
---

Run `hh elevate --project <dir>`. Plan the changes, ranked, with no fixed count. A visual pass may add a section treatment, an effect, or an image. Pass `--yes` only after the user says yes to a pick. `hh elevate detail` and `hh elevate copy` follow the same yes rule when they write files. The word Elevate here is the command name.

Never push. Never deploy. Never spend without the user's yes. Never create a GitHub repo.
