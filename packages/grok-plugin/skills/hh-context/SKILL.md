---
name: hh-context
description: Print what the Guide knows, and the last context audit.
user-invocable: true
---

Run `hh context` or `hh context --project <dir>`. Add `--audit` to print the last call's packet sections. The command reads the project and does not change it. `hh context repair` is the fix named by `hh doctor --context`.

Never push. Never deploy. Never spend without the user's yes. Never create a GitHub repo.
