user-invocable: true
---

Run `hh doctor` or `hh doctor --project <dir>`. Show the report as printed. The report covers node, git, grok, the session id, and the effort flag, and it warns when playwright, whisper, or pdftotext is missing. It does not print an auth result. Do not invent one. A failing check stays a failure.

Never push. Never deploy. Never spend without the user's yes. Never create a GitHub repo.
