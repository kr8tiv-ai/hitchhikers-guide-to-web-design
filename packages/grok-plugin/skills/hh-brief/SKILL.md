---
name: hh-brief
description: Draft or show the Site Brief. Approval needs the user's yes.
user-invocable: true
---

Run `hh brief` or `hh brief --project <dir>`. An idle brief is drafted. A pending or approved brief is shown and is not drafted again. Pass `--approve` only after the user says yes. That approves the brief and starts the next phase. Any other flag prints usage and exits 2.

Never push. Never deploy. Never spend without the user's yes. Never create a GitHub repo.
