# Design library schema

The library lives in `packages/knowledge/design-library/`. Galleries stay the interview Suggest cards. This library is build context: inspiration and vocabulary. Grok remixes an entry and does not reproduce it.

Field checks live in `packages/knowledge/src/design-library.ts` (`validateDesignEntry`). The command is `pnpm --filter @hitchhiker/knowledge run validate:design-library`. It requires at least 12 human-verified entries, a matching `index.json`, and a technique note for every technique name. Auto-verified entries from a later ingest are allowed. How to add, refresh, and retire is in [docs/design-library.md](../../../docs/design-library.md).

## Layout

| Path | Rule |
| --- | --- |
| `entries/<id>.json` | One entry. |
| `shots/<id>/<width>.webp` | Optional screenshots we took of the public page, 1440 and 375, under 300 KB. Never a gallery thumbnail or the site's own assets. The `shots/` tree is gitignored and regenerated on demand. |
| `techniques/<technique>.md` | One note. Headings include Prompt language, Perf cost, and Reduced motion. |
| `snippets/<id>/` | Only when `ingestMode` is `code`. A working snippet under 80 lines, the upstream `LICENSE` text, and a `CREDIT.md`. |
| `index.json` | Prebuilt tag index. Regenerated by ingest. Do not hand-edit. |
| `ingest-state.json` | Resumable ingest state. |
| `candidates.json` | URLs waiting for the policy gate. These are not entries. |

## Entry fields

| Field | Rule |
| --- | --- |
| `id` | Kebab slug, unique. |
| `kind` | `site`, `technique`, or `pattern`. |
| `title` | Short name. |
| `url` | Page or repository URL. |
| `source` | `aura`, `godly`, `awwwards`, `land-book`, `lapa`, `fwa`, `codrops`, `gsap-showcase`, `three-showcase`, `official-docs`, `original-note`, or `direct`. |
| `sourcePage` | Listing or docs page. Required. |
| `styleWorld` | A gallery world: `editorial`, `brutalist`, `3d-world`, `scroll-film`, `minimal-luxury`, `playful`. |
| `family` | A gallery family. `styleWorld` must match the family-to-world table in `packages/knowledge/galleries/SCHEMA.md`. |
| `moods` | 2 to 6 of: calm, warm, editorial, bold, dark, playful, luxurious, technical, organic, cinematic, minimal, maximal. |
| `sectionTypes` | One or more of: hero, story, gallery, cards, testimonial-free proof, pricing, contact, footer, transition. |
| `techniques` | File names from `techniques/`, at least one. |
| `libraries` | Any of: gsap, scrolltrigger, splittext, lenis, motion, three, r3f, ogl, glsl, css-scroll, view-transitions, howler, web-audio, vanilla. A name here does not forbid another library. |
| `promptLanguage` | 1 to 3 sentences of expert phrasing. No URL, no exclamation mark, no em dash. |
| `notes` | 1 or 2 sentences we wrote. Same prose rules. |
| `perfCost` | `low`, `medium`, or `high`. |
| `reducedMotion` | One sentence. |
| `sourceUrl` | Canonical URL. Dedupe key. |
| `license` | For `code`: SPDX `MIT`, `Apache-2.0`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `0BSD`, `Unlicense`, or `CC0-1.0`. Otherwise `none-stated` or `link-only`. |
| `creditLine` | Author, project, and link, as the license or the source asks. |
| `licenseTextPath` | Required for `code`. The saved license text. Absent for `feed` and `link-only`. |
| `ingestMode` | `code`, `feed`, or `link-only`. |
| `snippets` | Relative paths. Required for `code`. Empty for `feed` and `link-only`. |
| `shots` | Relative screenshot paths. May be empty. |
| `checked` | ISO date `YYYY-MM-DD`. |
| `verified` | `auto` or `human`. |
| `retired` | Boolean. A retired entry stays on disk and is not selected. |

`code` stores a small snippet plus the license text and credit line. `feed` and `link-only` store the link, our notes, and our screenshots. They do not store the page's code, copy, fonts, or images. GPL, AGPL, a missing license, and a custom license are `link-only` at most.

## Index

`index.json` maps `styleWorld`, `moods`, `sectionTypes`, `techniques`, and `libraries` to entry ids. Selection reads this index. It does not scan every file at prompt time and it does not use a vector store.

## Check

```powershell
pnpm --filter @hitchhiker/knowledge run validate:design-library
```
