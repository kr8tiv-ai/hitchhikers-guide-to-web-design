# lenis-smooth-scroll

## What it looks like

Lenis eases the native scroll and reports frames to the GSAP ticker.

## When it fits

Use it when the art direction asks for this kind of moment. It is one option among many, and a different library can carry the same idea.

## Prompt language

Lenis eases the native scroll and reports frames to the GSAP ticker. Name the technique, then change the composition so the page is not a copy.

## Libraries

Pick the library that fits the stack. GSAP, Three.js, Motion, Lenis, a shader, CSS, or vanilla can all carry a version of this.

## Perf cost

Perf cost: low or medium. Prefer transform and opacity.

## Reduced motion

Reduced motion keeps the content complete and drops the extra movement.
