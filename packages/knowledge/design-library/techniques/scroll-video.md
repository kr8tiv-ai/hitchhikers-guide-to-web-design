# scroll-video

## What it looks like

A muted sequence or clip scrubs with the scroll and keeps a poster.

## When it fits

Use it when the art direction asks for this kind of moment. It is one option among many, and a different library can carry the same idea.

## Prompt language

A muted sequence or clip scrubs with the scroll and keeps a poster. Name the technique, then change the composition so the page is not a copy.

## Libraries

Pick the library that fits the stack. GSAP, Three.js, Motion, Lenis, a shader, CSS, or vanilla can all carry a version of this.

## Perf cost

Perf cost: high when a canvas stays on screen. Keep a poster.

## Reduced motion

Reduced motion keeps the content complete and drops the extra movement.
