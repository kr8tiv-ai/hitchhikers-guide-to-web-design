# UX

Read the site brief and `BRAND.md` before you add a section. Do not invent a conversion rate, a lift, or any other marketing statistic.

## One primary action

Each page has one primary action. The button names the outcome in the words of `VOICE.md` when a sample exists. Learn More and Get Started are banned. Other actions stay quieter and do not compete with that button.
Source: hh-build-plan/RESEARCH-ADDENDUM.md section 9.

## No dark patterns

No dark patterns. No fake countdown, and no timer that resets when it expires. No pre-checked extra. No cost that appears only at the last step. No item added without a clear yes. No button that shames a refusal. A deadline is allowed only when the brief states a real one.
Source: https://www.nngroup.com/articles/deceptive-patterns/
Source: https://www.nngroup.com/articles/sneaking/
Source: hh-build-plan/RESEARCH-ADDENDUM.md section 9.

## Forms

Every field has a visible label. Placeholder text is not the label. An error names the field and says how to fix it. Set `inputmode` for email, telephone, number, and URL fields. Set `autocomplete` to the token for that field, such as name, email, tel, or street-address.

A control is at least 44 CSS pixels on the shorter side.
Source: hh-build-plan/CONTEXT-PACKAGE.v2.md section 15.5.
Source: hh-build-plan/RESEARCH-ADDENDUM.md section 9.

## Trust

Proof is a fact already in `BRAND.md`. Do not invent a testimonial, a logo strip, a star rating, or a customer count. If the proof is missing, leave the block out.

## Navigation and the hero

The hero states one idea and the primary action. Navigation keeps that action findable. Do not hide it in a control that only a pointer can open. The menu itself follows the keyboard rules in the accessibility pack.

## Page shape

Funnel, brand, or hybrid is a structure from the brief, not a skin. A funnel page has one offer and one primary action. A brand page may offer more than one path and still has one primary action. A hybrid page may open with a signature moment and then return to that action.
