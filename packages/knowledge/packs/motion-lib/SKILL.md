# Motion

whileInView with viewport once reveals a block a single time. MotionConfig reducedMotion user and useReducedMotion follow the visitor. useScroll and scrollYProgress tie a value to the page. Layout animations stay on small controls. LazyMotion keeps the island smaller when that matters. A playful brand can use a spring. A calm brand uses a short tween.

The words stay selectable. Motion is one owner for the properties it animates.
