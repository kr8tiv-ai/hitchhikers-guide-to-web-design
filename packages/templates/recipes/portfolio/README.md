# Portfolio

A content collection for work: title, summary, year, and a cover path under the site. No env vars. No account.

Astro can add the fields beside the blog collection. Next.js and Vite read the same shape from Markdown or JSON in `content/portfolio`. Covers go through `optimize-media` so the page gets AVIF and WebP sizes.

The sample year is a calendar year the client supplies. Do not invent a count of projects.
