# Desk

When an earlier answer names sites, the gallery question names those sites and links to the gallery. With no sites named, it still asks to look at a few together.

An unsent answer stays on this machine. The desk saves it in this browser as you type or dictate, and keeps a copy in the project folder. Coming back to the desk, reloading, or starting the app again restores those words on the same question. Answer or Skip removes the draft after the interview moves on. A failed Answer leaves the words in place.

## Brand kit and design library

The same interview writes `.hitchhiker/brand/BRAND.md` and `src/data/brand.ts`. The brief page shows that kit. Each section prompt carries two to four design-library entries as inspiration, with the line "Take the thinking, not the skin." The library format, the ingest commands, and the aura.build parity table are in [design-library.md](design-library.md).

## Imagine

Settings has an on/off control for an embedded browser. The profile stays in the project's `.hitchhiker/browser-profile`. You sign in to your own Grok account yourself. The desk drives pages in that profile and does not read, export, or extract cookies, tokens, or credentials. Off means that path is not built. The Grok CLI stays first. An optional API key is labelled billed per use, and the desk does not switch to it on its own. If no path can run, the slot is blocked and no placeholder is written. A hero film is saved as soon as the file is ready. Sound stays off until a labelled control is pressed.

## Pause and Retry

A pause that is still there after a restart stays until you press Retry or Resume. Retry on a failed row clears that pause and runs the prompt. The row says so: "The queue is paused. Retry clears the pause and runs this prompt." An automatic retry does not clear a pause. While a later prompt is still running, the banner names that prompt and says it will finish first. After it settles, the banner says paused after that prompt.
