# Don't Panic

This is the interview phase. Run `hh doctor` before you begin. The report covers node, git, grok, the session id, and the effort flag. It warns when playwright, whisper, or pdftotext is missing. It does not print an auth result.

`/hh-dont-panic` starts or resumes the interview. One question at a time. The three moves are Answer, Suggest for me, and Skip. A skip writes a marked assumption.

The product introduction, the command list, and the test commands are in the [README](../README.md).
