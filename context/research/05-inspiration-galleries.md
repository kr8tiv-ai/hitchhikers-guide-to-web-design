# 05 · Inspiration galleries: where to send users, and what each is good for

Research date: 2026-10-05. Every URL below returned a live page today. A few (SiteInspire, Behance, Dribbble, CSSDA) block automated fetches, but they're well-known public sites. The "good for" notes combine each site's own positioning (quoted where I captured it) with my assessment. The interview's reference step should link users straight into the filtered view that matches their chosen style and motion appetite.

## How the app should use galleries

1. **Guided reference capture (Matt's rule: 3–5 sites, not 20).** "Too much context confuses the model" (*AntiHero Website Masterclass*, Step 3). Cap the reference board at 5, with a required "what exactly do you love here" note for each (type / scroll / layout / color / motion / menu).
2. **Smart deep links by style world** (from 03):
   - Immersive 3D → Godly *3D* filter, Awwwards tag `three-js`, The FWA
   - Product hero → Awwwards `e-commerce` + `3d`, Lapa Ninja *3D Websites*
   - Scroll storytelling → Awwwards `storytelling`, Codrops scroll demos
   - Playful illustration → Awwwards `illustration` + `colorful`, Dribbble motion
   - Type-led minimal → SiteInspire, Minimal Gallery, Typewolf
   - Mobile UX patterns → Mobbin, Land-book *Mobile*
3. **URL ingestion.** When a user pastes a URL, the app (a) captures desktop and mobile screenshots with Playwright, (b) records detected libraries by sniffing scripts and globals (`gsap`, `THREE`, `Lenis`, `__NEXT_DATA__`, Webflow), (c) asks the user to circle or annotate the part they love, and (d) writes a reference card: `{url, screenshot, liked_aspects, detected_stack, steal_the_thinking_notes}`. Matt's masterclass notes that links help "because your AI can read a site's code", so the reference card should also hold a short structural summary.
4. **Never copy assets.** The reference card stores *principles*. Anything actually borrowed (a Codrops demo, a font, a model) goes into `CREDITS.json` in the same commit.
5. **Optional integrations:** a Mobbin MCP (paid) for UI patterns. Everything else is browse-and-screenshot.
