## Goal

Build the runner that will execute one site prompt with `grok` in headless mode. Flags include `--no-auto-update`, `--output-format streaming-json`, `--effort`, and `--max-turns`. The session is fresh. Tests inject a spawn function and never call a real grok. If drive approval is missing, the runner throws before spawn.

## Context for a fresh session

runPrompt({ bin, promptPath, effort, maxTurns, sessionMode, approval, spawnImpl }) builds an argv array. `--always-approve` is absent in this prompt. Sandbox flags arrive in the next prompt. sessionMode uuid passes `--session-id` only if the caller supplies a uuid. sessionMode alias does not pass `--session-id`. sessionMode unknown throws RunConfigError and tells the user to run hh doctor. A new uuid is generated by the caller, not reused from the previous prompt. The test asserts two runs received different ids. streaming-json is the format. The function reads the prompt file only to confirm it exists when a readImpl says so. It does not parse the whole Guide repo. Exit code from spawn is returned. Non-zero throws RunFailed after capturing stderr trimmed to 2,000 characters.

## Interfaces and data shapes

```ts
export interface RunRequest {
  model: string;
  cwd: string;
  promptText: string;
  bin: string;
  promptPath: string;
  effort: "medium" | "high" | "xhigh";
  maxTurns: number;
  sessionMode: "unknown" | "uuid" | "alias";
  sessionId?: string;
  approved: boolean;
}

export function buildArgv(req: RunRequest): string[];
export function runPrompt(req: RunRequest, spawnImpl: (argv: string[]) => Promise<{ code: number; stderr: string }>): Promise<void>;
```

## Steps

1. buildArgv includes `-p` with the assembled prompt (RULES.md text + the prompt file + the read_first files resolved to @file references, stable prefix first), `-m` with the model from config (default grok-4.7; Q25 model selectable), `--cwd` with the project directory, `--no-auto-update`, `--output-format`, `streaming-json`, `--effort`, the effort value, `--max-turns`, and the number. If the assembled prompt exceeds the OS argv limit, pass it with `--prompt-file` (grok 1.0.46 has it) and record which path was used.

2. uuid mode without sessionId throws. uuid mode with a non-uuid throws. Use a simple 8-4-4-4-12 hex check.

3. alias mode argv does not contain `--session-id`.

4. unknown mode throws before spawn. The test's spawn throws if called.

5. approved false throws before spawn.

6. Two uuid runs in the test pass two ids and assert they differ. The runner does not generate them. The test does.

7. Non-zero code throws and the error does not include the whole prompt text, only the path.

8. Do not pass `--always-approve`. The test fails if the argv contains it.

9. Export the functions. Wire the orchestrator test script.

## Edge cases

- maxTurns under 1 or over 80 throws.
- effort `low` throws.
- bin with a space is still one argv entry because you pass an array. buildArgv returns the args after the bin. The bin is separate.
